# Kredit & inspirasi

Aplikasi ini berdiri di atas karya banyak orang. Halaman ini ucapan terima kasih; lisensi resmi setiap aset ada di [NOTICE.md](../NOTICE.md), dan dasar ilmiah aturan latihan ada di [REFERENCES.md](REFERENCES.md). Tidak ada logo pihak ketiga di repo ini, hanya nama dan tautan.

## Data & aset

- **[free-exercise-db](https://github.com/yuhonas/free-exercise-db)** (Yuhonas dan kontributor): gambar awal dan akhir gerakan di detail teknik. Public domain (Unlicense).
- **Peta otot SVG:**
  - **[MuscleMapJS](https://github.com/abdofallah/MuscleMapJS)**: path tubuh depan dan belakang.
  - **[MuscleMap SwiftUI](https://github.com/melihcolpan/MuscleMap)**: asal path MuscleMapJS.
  - **[react-native-body-highlighter](https://github.com/HichamELBSI/react-native-body-highlighter)**: nama dan bentuk region.
  - **[react-body-highlighter](https://github.com/giavinh79/react-body-highlighter)**: acuan pemetaan region saat merancang peta otot.
  - Semuanya MIT.
- **Font:** [Archivo](https://github.com/Omnibus-Type/Archivo) (Omnibus-Type) dan [Geist Mono](https://github.com/vercel/geist-font) (Vercel bersama basement.studio), SIL Open Font License.
- **Ikon:** beberapa path dari [Feather](https://github.com/feathericons/feather) dan [Lucide](https://github.com/lucide-icons/lucide).

## API & platform

- **[intervals.icu](https://intervals.icu):** sumber aktivitas, wellness, dan zona, sekaligus jalur workout ke jam lewat kalendernya. Forum dan dokumentasi API-nya menjadi rujukan semua integrasi di sini.
- **[Vercel](https://vercel.com):** hosting dan tombol Deploy.
- **[Upstash](https://upstash.com):** Redis opsional untuk sinkron, di akun pengguna sendiri.
- **[GitHub](https://github.com):** repo, Actions (CI, rilis, pembaruan salinan), Discussions.

## Referensi desain

- **Kartu story lari** (Easy 3K, Mini Interval, Fartlek, This Week): kartu ringkasan lari bergaya label yang menjadi titik awal design system "Tag" ([DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)).
- **[taste-skill](https://github.com/Leonxlnx/taste-skill)** (Leonxlnx): skill `redesign-existing-projects` dan `design-taste-frontend`, dipakai sebagai protokol audit desain.
- **[skills Emil Kowalski](https://github.com/emilkowalski/skills)**: `emil-design-eng` (prinsip motion dan detail antarmuka) serta `mobile-native` (rasa aplikasi native di web).

## Inspirasi konsep

- **openGym**: hanya **konsep** yang diambil, yaitu double progression dengan rentang rep terlihat, timer istirahat, dan target yang menjelaskan alasannya ([STRENGTH-HIDUP.md](STRENGTH-HIDUP.md) §5). Karena openGym berlisensi AGPL-3.0, tidak ada kode, teks, atau aset UI yang disalin.

## Alat

- [Next.js](https://nextjs.org) dan [React](https://react.dev): kerangka aplikasi.
- [TypeScript](https://www.typescriptlang.org) dan [Tailwind CSS](https://tailwindcss.com): bahasa dan styling.
- [Vitest](https://vitest.dev), [Playwright](https://playwright.dev), dan [axe-core](https://github.com/dequelabs/axe-core): unit test, end-to-end, aksesibilitas.
- [actionlint](https://github.com/rhysd/actionlint): pemeriksa workflow GitHub Actions.
